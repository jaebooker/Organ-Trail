# The Organ Trail

Hunt for human organs with your band of savages. A wasteland caravan game in the style of the 1985 Oregon Trail.

Plain HTML, CSS and JavaScript with no build step. Open `index.html`, or deploy the folder to any static host.

- `js/Game.js`: `Caravan`, `EventManager`, `UI` and `Game` classes
- `js/art.js`: the pixel scene, drawn on a 320x132 canvas

Play with the number keys, space bar, or by tapping.
